# 纯净桌面切换器 Pure Desktop Switcher

> 一键在「正常桌面」和「纯净桌面（只留壁纸）」之间切换的小工具。
> **不移动、不删除任何文件**，只是隐藏/显示桌面图标这一层。
>

## ✨ 功能特点

- **一键切换**：全局热键 `Ctrl + Alt + D`，或左键点击托盘图标
- **绝对安全**：桌面文件一个都不动，只是显示/隐藏图标层
- **状态可见**：托盘图标实时显示当前状态
  - 头像 = 正常桌面（图标显示中）
  - 头像 + 绿色圆点 = 纯净桌面（只留壁纸）
- **可选隐藏任务栏**：想要 100% 纯净的壁纸，菜单里勾一下就行
- **开机自启**：菜单里勾选即可，无需配置
- **零依赖、超轻量**：纯 Python 标准库 + Windows 系统 API，无需安装任何第三方库

## 🚀 快速开始

### 环境要求

- Windows 10 / 11（64 位）
- 已安装 Python 3.8+（安装时勾选 *Add to PATH*；装了 Python 就自动带 `pythonw.exe`）

### 三步上手

1. **下载本项目**：点右上角 `Code → Download ZIP`，解压到任意文件夹
2. **双击 `纯净桌面切换器.pyw`**：托盘区出现头像图标，即启动成功（无黑窗口）
3. **按 `Ctrl + Alt + D`**：见证奇迹，桌面瞬间变干净！再按一次，图标全部回来

### 建议设置

右键托盘图标 → 勾选「**开机自动启动**」，以后开机它就常驻托盘待命。

## 📖 详细使用说明

| 操作 | 效果 |
|---|---|
| `Ctrl + Alt + D` | 全局热键，任何界面下都能切换 |
| 托盘左键 | 同样是切换 |
| 托盘右键 | 打开功能菜单 |

托盘右键菜单：

- **切换到 正常桌面 / 纯净桌面**：核心功能
- **同时隐藏任务栏**：壁纸 100% 无遮挡（再点一次恢复；程序退出时也会自动帮你恢复）
- **开机自动启动**：写入注册表 `HKCU\...\Run`，仅当前用户生效
- **重启资源管理器**：桌面状态偶尔没刷新时用
- **关于 / 退出**

## ❓ 常见问题（FAQ）

**Q1：按了热键没反应？**
- 看托盘有没有头像图标：没有的话，双击 `纯净桌面切换器.pyw` 启动
- 热键可能被其他软件占用（如截图/翻译工具）：直接用托盘左键切换，或换个软件让出热键

**Q2：图标隐藏后，怎么手动恢复？**
- 再按一次 `Ctrl + Alt + D` / 点一下托盘图标
- 或右键桌面 → 查看 → 显示桌面图标（系统自带开关，本工具用的就是它）

**Q3：我的桌面文件会被删掉或移动吗？**
- **不会。** 工具只切换图标层的显示状态，文件原地不动。即使工具卸载了，文件也都在

**Q4：纯净模式下桌面还能右键吗？**
- 能。隐藏的只是图标，桌面右键菜单、个性化设置都正常

**Q5：程序出问题怎么排查？**
- 程序目录下的 `PureDesktopSwitcher.log` 记录了运行日志，提 issue 时可附上

## 🧙 进阶：自定义托盘头像

想把托盘图标换成你自己的头像？只需一条命令（在 `tools` 目录下）：

```bash
python make_icons.py 你的图片.jpg
```

脚本会自动生成两个图标（原始版 + 带绿色圆点的纯净模式版），重启工具即可生效。
仅用 Python 标准库 + Windows GDI+ 实现，无任何第三方依赖。

## 🔧 命令行模式（可选）

适合喜欢脚本化/自己配快捷键的用户：

```bash
python 纯净桌面切换器.pyw --status   # 查看当前状态
python 纯净桌面切换器.pyw --toggle   # 切换一次后退出
python 纯净桌面切换器.pyw --hide    # 隐藏桌面图标
python 纯净桌面切换器.pyw --show    # 显示桌面图标
```

## 🧠 工作原理

Windows 桌面图标本质是资源管理器桌面窗口里的一个列表控件。本工具通过三种手段组合切换它的可见性（互为保险）：

1. 向桌面窗口发送资源管理器原生命令 `WM_COMMAND 0x7402`（即「右键桌面 → 查看 → 显示桌面图标」）
2. 读写注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\HideIcons`
3. 直接对桌面图标列表（SysListView32）执行 `ShowWindow`

全程不触碰任何文件，关机重启后状态也会保持。
